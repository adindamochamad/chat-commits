Status user: **sudah Join** Devpost. Indonesia **eligible**.

## Lulus jika

- 18+ (atau usia dewasa setempat, yang lebih tua)
- Individu atau tim individu, **bukan** atas nama PT/organisasi
- Bukan karyawan/agen Amazon, OpenAI, Devpost, juri, atau keluarga serumah
- Proyek **baru** sejak 23 Oct 2026 10:00 PDT
- Terhubung Twitch + dibangun dengan OpenAI Codex + Session ID valid

- Submit organisasi
- Reuse repo lama apa adanya (jangan fork `send-hold` sebagai submission)
- Tidak pakai Codex / tidak ada Session ID
- Negara sanksi OFAC / daftar rules section 3
