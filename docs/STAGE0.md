# Stage 0 — Competition Brief

Kompas. Setiap ide dinilai: cocok brief ini atau tidak.

```
COMPETITION BRIEF
├── Arketipe        : Hybrid — Corporate/Sponsor + Online Async Video + Elite ($25k)
├── Domain          : Gaming / creator tools × AI coding agent
├── Winning Formula : Hidup di Twitch + Codex terlihat di produk DAN di proses build + video 3 menit dengan hook 10 detik
├── Bobot Penilaian : Stage 1 pass/fail (tema + Codex). Stage 2 25%×4: Innovation, Impact, Tech+Codex, Design. Tie-break = urutan itu.
├── Profil Juri     : OpenAI Codex, Twitch DevRel, Amazon. Adopsi produk sponsor + layak panggung TwitchCon.
├── Median Threat   : GPT chatbot, AI mod, Twitch Plays, poll overlay, chat summary, TTS, clip summarizer
├── Diferensiasi    : Codex adalah mesin live di overlay, bukan cuma IDE di belakang layar
├── Prize Stacking  : Satu track. Target top 5.
└── Effort          : ide 10% / build 50% / polish 15% / video+submit 20% / buffer 5%
```
